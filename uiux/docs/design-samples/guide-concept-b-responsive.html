02Semantic Colors

UI 상태를 표현하는 의미론적 컬러입니다. 이 4가지 외의 색상을 상태 표현에 사용하지 마세요.

토큰값상태사용 예시
--color-success #80B430 성공 저장 완료, 승인, 통과
--color-danger #E43E3E 오류 삭제 경고, 유효성 실패
--color-warning #ffbe0b 주의 진행률 바, 경고 안내
--color-info #2269D1 정보 링크, 안내 메시지

03Button Tokens

v3.0 Breaking Change--btn-line이 삭제됐습니다. 같은 값인 --btn-default-border-color로 일괄 교체하세요.
버튼 토큰 전체
root-tokens.css — buttons 
/* Primary */
--btn-main:                #5C61D4;
--btn-main-dark:           #4549AB;  /* hover */

/* CTA (반전) */
--btn-revers:              #FA7C35;
--btn-revers-dark:         #F86A0E;  /* hover */

/* Line / Default */
--btn-default-border-color: #DDDDDD; /* 구 --btn-line */
--btn-default-font-color:   #404040;

/* Disabled */
--btn-disabled-border-color:#DDDDDD;
--btn-disabled-bg-color:    #f9f9f9;
--btn-disabled-font-color:  #8d96a5;
