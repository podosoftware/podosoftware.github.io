Primary Palette

브랜드 컬러 스케일입니다. --primary-500이 기준이며 숫자가 클수록 어두워집니다. 직접 hex를 쓰지 말고 반드시 토큰을 사용하세요.

50#F8F9FD
100#F2F2FC
200#EBEBFA
300#999CE4
400#7A7EE8
500★#5C61D4
600#4549AB
700#37396D
800#0A0B25
root-tokens.css 
:root {
  --primary-50:  #F8F9FD;
  --primary-100: #F2F2FC;
  --primary-200: #EBEBFA;
  --primary-300: #999CE4;
  --primary-400: #7A7EE8;
  --primary-500: #5C61D4; /* ★ 메인 브랜드 */
  --primary-600: #4549AB;
  --primary-700: #37396D;
  --primary-800: #0A0B25;
}

Semantic Colors

기능별 의미를 가진 컬러입니다. UI 상태(성공, 경고, 오류)에 사용합니다.

토큰값역할사용처
--color-success#80B430success완료, 저장, 통과
--color-danger#E43E3Edanger오류, 삭제 경고
--color-warning#ffbe0bwarning주의, 진행 상태
--color-info#2269D1info안내, 링크

Button Tokens

BREAKING: v3.0--btn-line이 삭제됐습니다. --btn-default-border-color로 교체하세요.
buttons 
--btn-main:               #5C61D4; /* primary */
--btn-main-dark:          #4549AB; /* primary:hover */
--btn-revers:             #FA7C35; /* CTA */
--btn-revers-dark:        #F86A0E; /* CTA:hover */
--btn-default-border-color:#DDDDDD; /* line btn */
--btn-disabled-bg-color:  #f9f9f9;
--btn-disabled-font-color:#8d96a5;

Text Tokens

v3.0에서 텍스트 색상이 시맨틱 토큰으로 통합됐습니다. 기존 --text-color, --default-font-color는 하위 호환으로만 유지됩니다.

typography tokens 
--text-primary:  #262527; /* 강조 · 제목 */
--text-body:     #46464F; /* 본문 기본   */
--text-secondary:#8e8e93; /* 보조 설명   */
--text-disabled: #B8B8B8; /* 비활성      */

/* deprecated — next major 에서 제거 예정 */
--default-font-color: var(--text-body);
--text-color:         var(--text-primary);
--text-color02:       var(--text-secondary);
