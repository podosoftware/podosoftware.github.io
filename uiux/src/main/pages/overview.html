Podo Publisher Guide

이 가이드는 퍼블리셔가 따라야 할 디자인 시스템과 컴포넌트 사용법을 정의합니다.

2025-01-20 5 min read v3.0 기준

01Purpose

이 문서는 모든 퍼블리셔가 준수해야 하는 디자인 시스템과 개발 가이드라인을 제공합니다. 일관된 사용자 경험과 코드 품질을 유지하기 위해 여기서 정의한 규칙을 따릅니다.

02가이드 구조

이 가이드는 다음과 같이 구성됩니다:

섹션내용
기본 원칙 그리드 시스템, 타이포그래피, 간격 규칙 등 기본 설계 원칙
디자인 토큰 색상, 폰트, 크기 등 재사용 가능한 설계 요소
아이콘 시스템 아이콘 사용법 및 전체 아이콘 목록
컴포넌트 버튼, 폼, 테이블 등 UI 컴포넌트
Kendo UI Kendo UI 라이브러리 사용법 및 커스터마이징

03빠른 시작

처음 프로젝트를 시작한다면 빠른 시작 페이지에서 기본 설정 방법을 확인하세요.

04최신 업데이트

주요 변경사항

  • 새로운 타이포그래피 규칙
  • 반응형 디자인 강화
