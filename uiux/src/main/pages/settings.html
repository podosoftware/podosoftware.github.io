환경 설정

프로젝트에서 이 가이드를 사용하기 위한 기본 설정을 진행합니다.

2025-01-15 8 min read v3.0에서 업데이트됨

01CSS 설정

프로젝트에서 다음 CSS 파일들을 로드해야 합니다:

HTML head 
/* 토큰 및 스타일 시트 */
<link rel="stylesheet" href="/assets/css/tokens.css">
<link rel="stylesheet" href="/assets/css/style.css">

02JavaScript 설정

페이지 하단에 다음 스크립트를 추가합니다:

HTML body 끝 
<script src="/assets/js/baseLayout.js"></script>
주의: jQuery 라이브러리가 선행 로드되어야 합니다.

03HTML 구조

기본 레이아웃 구조는 다음과 같습니다:

기본 레이아웃 
<header id="topbar">...</header>
<nav id="sidebar">...</nav>
<div id="layout">
  <div id="main">
    <!-- 페이지 콘텐츠는 여기에 동적으로 로드됨 -->
  </div>
</div>
